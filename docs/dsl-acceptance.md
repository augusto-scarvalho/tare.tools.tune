# DSL implementation acceptance map

The later [efficiency correction record](dsl-efficiency.md) covers task/service parity, incremental refinements and compact responses. This map retains the original M0–M7 evidence.

[Reviewed Astra plan](plans/2026-10-31-dsl/PLAN.md) · [Verification record](dsl-implementation.md) · [Token evidence](dsl-benchmarks.md)

The engineering roadmap is implemented. Version 1 remains **experimental**: total-token targets failed in the scripted comparison, and the bounded live pilot was blocked by its sandbox. This map separates delivered behavior from those unqualified hypotheses. The original plan and audit artifacts remain unchanged.

The generated [vocabulary](dsl-reference.json) enumerates result types, fields/defaults/ranges/units, transforms and capability boundaries. Enumeration tests prepare every catalog example without rendering or asset IO. Resource tests reject expansion bombs, excessive generated Cue capture parts, Modal/scatter work, long/slow speech and decoded PCM header sizes before the prohibited DSP/read allocation. Limits are estimates and ceilings, not process isolation; worker timeouts remain relevant.
